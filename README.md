# ネオン・リンガ

YouTube などで流れている**英語の音声を、リアルタイムで日本語字幕にする** Android アプリです。
ライブ配信にも対応しています。サイバーパンク風の画面で、英語が「解読」されるように日本語へ変わっていきます。

## 特長
- **無料で使える**:音声の文字起こし(Vosk)と翻訳(ML Kit)は、端末の中だけで動きます
- **より自然な訳も選べる**:Gemini や DeepL の API キー(無料枠あり)を入れると、口語的で自然な訳になります
- **2つの表示方法**:YouTube アプリの上に字幕ウィンドウを重ねる / アプリ内で YouTube と字幕を並べる
- **訳の口調を選べる**:「まじめ」「ふつう」「ワル」の3段階(Gemini / DeepL 使用時)
- **見た目を変えられる**:4種類のテーマ、文字サイズ、字幕ウィンドウの高さ、文字の色

## 動作環境
- Android 10 以降(英語音声 → 日本語字幕)
- 初回のみ、翻訳モデル(約30MB)のダウンロードにネット接続が必要です

## インストール
1. 下の「Assets」から 最新版の `NeonLingua-v(バージョン).apk` をダウンロード
2. ダウンロードしたファイルを開いてインストール(「提供元不明のアプリ」の許可を求められたら許可)
3. 「他のアプリの上に重ねて表示」が許可できないときは、
   設定 > アプリ > ネオン・リンガ の右上「⋮」から「制限付き設定を許可」を選んでください

## 使い方
1. アプリを開き、「▶ 開始(字幕ウィンドウ)」または「▶ 開始(アプリ内YouTube)」を押す
2. マイク・通知・画面共有などの許可を求められたら許可する(音声は端末の外に送られません※)
3. YouTube で動画を再生すると字幕が表示されます。止めるときは字幕の「■ 終了」

※ Gemini / DeepL を使う設定にした場合のみ、文字起こしした英文がそれぞれのサービスに送信されます。

## Gemini / DeepL を使うには(任意)
設定(⚙)の「翻訳API」にキーを入力します。入力欄の下のリンクから無料で取得できます。
キーはこの端末の中にだけ保存されます。

## 注意
- 本アプリは YouTube・Google・DeepL とは関係のない個人制作のアプリです
- 音声の取り込みを許可していないアプリ・動画では字幕が出ないことがあります
- 認識・翻訳の精度は音声の状態によって変わります
